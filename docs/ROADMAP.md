# Roadmap

## 0.1–0.4 — creative graph/editor foundation ✅

Universal Creative Graph, operation/history boundary, durable projects/media, Canvas/Cut/Motion/Agent, timeline editing, text/shapes, audio semantics and Deliver manifests.

## 0.5–0.7 — media-kernel/container foundation ✅

Versioned kernel protocol, Worker scheduling, MP4/MOV/WebM/WAV demux/mux foundations, WebCodecs adapters, thumbnails/proxies, fMP4 and classic MP4 export paths.

## 0.8 — integrated browser media engine ✅

Worker Cut playback, streamed decode results, segmented proxy jobs, full timeline Deliver, progressive sinks, HEVC/AV1 MP4 entries, presentation metadata, GPU texture/effect kernels and offline loudness automation.

## 0.9 — bounded IO + resumable composition delivery ✅

- range-addressable media sources;
- sparse classic MP4/MOV and WebM indexes;
- evaluated multi-layer Cut playback;
- WebGPU layer composition with deterministic Canvas fallback;
- streaming proxy decoder→encoder handoff;
- resumable chunked final fMP4 render/assembly;
- terminal streaming-WebM Cues;
- shared IndexedDB lifecycle/quota helpers;
- explicit SDR/HDR GPU color policy;
- conformance/performance budgets.

## Next — professional media semantics

- sparse fMP4/live WebM source indexes;
- transitions and masks;
- non-normal GPU blend modes and richer effect graph;
- full color-management/HDR working-space pipeline;
- compressed-audio streaming/range decode and buses;
- seekable classic-MP4 finalization;
- nested/compound compositions and multicam;
- captions/transcripts and scopes/meters;
- operation-log collaboration and production Agent evaluation.

## Long-term

Native/WASM codecs and effects, 3D/scene workspace, MIDI/music composition, distributed rendering, plugin SDK, interchange bridges and responsive multi-output campaign automation.
